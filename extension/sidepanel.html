👋 Welcome to SciKick

The side panel needs a local helper server to run. Open a terminal and run:

1. Clone the repo

git clone https://github.com/JHCCoder/SciKick.git && cd SciKick

2. Start the server

./start.sh

Once it's running, click Retry below, then enter your API key in ⚙ Settings. Google Drive is set up later — when you open a Drive folder, the panel will guide you.

⚠️ Backend server not running

The assistant needs a local server to work.

If you've already set up the background service, the server should start automatically when you log into your Mac. If it's still not working, make sure your project folder isn't in ~/Desktop or ~/Documents — macOS blocks background services from those locations.

Otherwise, open a terminal and run:

cd SciKick && ./start.sh

Then click Retry below or the ⟳ button.

📁 Google Drive access needed

To read this Drive folder, SciKick needs its own Google Drive credentials. In a terminal, run:

./start.sh --drive

That runs a one-time Google Cloud setup (it explains each step). Then come back here and click Check again.

🔗 Connect your Google account

SciKick has its Drive credentials — sign in with Google so it can read your folder.

A Google sign-in page opens in a new tab. After you approve, come back and click Check again.
